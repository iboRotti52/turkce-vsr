# Checkpoints

Bu dizin bilinçli olarak boş başlangıç durumundadır.

- Eski deney checkpoint'leri kalıcı olarak silinmiştir.
- Hiçbir eski ağırlık initializer, baseline veya kanıt kabul edilmez.
- Yeni checkpoint ancak `research/CANDIDATE.md` içindeki tek kanonik modele bağlı, provenance bilgileri eksiksiz bir probe veya training run tarafından üretilebilir.
- Full-training checkpoint'i yalnız `GEMINI.md` içindeki readiness kapılarının tamamı geçildikten sonra üretilebilir.
